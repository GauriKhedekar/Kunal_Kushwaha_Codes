# Striver A2Z — 2 Pointer & Sliding Window

## Pattern 1: Constant Window

### When to use

```text
K consecutive elements
Fixed window size
```

### Algorithm

1. Calculate the first window.
2. Slide the window:

   * Remove `arr[L]`
   * Move `L`
   * Move `R`
   * Add new `arr[R]`
3. Update the answer.

### Java Template

```java
int L = 0;
int R = K - 1;

int sum = 0;

// First window
for (int i = L; i <= R; i++) {
    sum += arr[i];
}

int maxSum = sum;

while (R < n) {

    // Remove element leaving window
    sum -= arr[L];
    L++;
    R++;
    // Add new element entering window
    sum += arr[R];

    // Update answer
    maxSum = Math.max(maxSum, sum);
}
```

### TC / SC

```text
Time:  O(N)
Space: O(1)
```

### Key idea

```text
Remove what leaves
+
Add what enters
```

# Pattern 2: Longest Subarray / Substring + Condition

### When to use

```text
Longest subarray / substring
+
Some condition
```

Example:

```text
Longest subarray with sum <= K
```

---

## Brute Force

### Algorithm

Generate all subarrays using:

```text
i = start
j = end
```

Maintain the sum and check the condition.

### Java

```java
int maxLen = 0;

for (int i = 0; i < n; i++) {

    int sum = 0;

    for (int j = i; j < n; j++) {

        sum += arr[j];

        if (sum <= K) {
            maxLen = Math.max(
                maxLen,
                j - i + 1
            );
        }
    }
}
```

### TC / SC

```text
Time:  O(N²)
Space: O(1)
```

### Small tweak

If numbers are **positive** and:

```text
sum > K
```

there is no point expanding further.

```java
if (sum > K) {
    break;
}
```

# Pattern 2: Sliding Window

### Algorithm

```text
Expand R
   ↓
Add arr[R]
   ↓
Window invalid?
   ↓
Shrink from L
   ↓
Window valid
   ↓
Update maximum
```

### Java Template

```java
int L = 0;
int R = 0;

long sum = 0;
int maxLen = 0;

while (R < n) {

    // Expand
    sum += arr[R];

    // Shrink while invalid
    while (sum > K) {
        sum -= arr[L];
        L++;
    }

    // Window is valid
    maxLen = Math.max(
        maxLen,
        R - L + 1
    );

    R++;
}
```

### TC / SC

```text
Time:  O(2N) = O(N)
Space: O(1)
```

### Why O(N)?

```text
R moves at most N times
L moves at most N times

Total = O(2N)
      = O(N)
```

# Pattern 3: Number of Subarrays + Condition

### When to use

```text
Number of subarrays
+
Condition
```

Example:

```text
Count subarrays with sum exactly K
```

### Main trick

Convert:

```text
sum == K
```

into:

```text
sum <= K
-
sum <= K - 1
```

Therefore:

```text
count(sum == K)
=
count(sum <= K)
-
count(sum <= K - 1)
```

### Algorithm

Solve:

```text
count(sum <= K)
```

and:

```text
count(sum <= K - 1)
```

using the sliding-window/counting idea, then subtract.

### Core counting idea

For a valid window `[L ... R]`:

```text
Number of valid subarrays ending at R
= R - L + 1
```

### Java Template for `count(sum <= K)`

```java
long countSubarrays(int[] arr, int K) {

    int L = 0;
    long sum = 0;
    long count = 0;

    for (int R = 0; R < arr.length; R++) {

        sum += arr[R];

        while (sum > K) {
            sum -= arr[L];
            L++;
        }

        count += R - L + 1;
    }

    return count;
}
```

Then:

```java
long answer =
    countSubarrays(arr, K)
    - countSubarrays(arr, K - 1);
```

### TC / SC

```text
Time:  O(N)
Space: O(1)
```

# Pattern 4: Shortest / Minimum Window

### When to use

```text
Shortest / minimum subarray
+
Condition
```

### Algorithm

```text
Expand R
   ↓
Window becomes valid
   ↓
Shrink L while valid
   ↓
Update minimum
```

### Java Template

```java
int L = 0;

long sum = 0;
int minLen = Integer.MAX_VALUE;

for (int R = 0; R < n; R++) {

    // Expand
    sum += arr[R];

    // Shrink while valid
    while (sum >= K) {

        minLen = Math.min(
            minLen,
            R - L + 1
        );

        sum -= arr[L];
        L++;
    }
}
```

### TC / SC

```text
Time:  O(N)
Space: O(1)
```

# Important Tweaks / Things to Remember

## 1. Window length

```java
R - L + 1
```

---

## 2. Expansion vs Shrinking

```text
R → Expand
L → Shrink
```

---

## 3. Longest vs Minimum

```text
LONGEST
→ shrink when INVALID
→ then take MAX
```

```text
MINIMUM
→ shrink while VALID
→ take MIN
```

---

## 4. `while` → `if` Optimization

For some **longest-length-only** problems, Striver optimizes:

```java
while (sum > K) {
    sum -= arr[L];
    L++;
}
```

to:

```java
if (sum > K) {
    sum -= arr[L];
    L++;
}
```

Reason:

```text
Already have maxLen = X

If current window becomes invalid,
we don't need to shrink below X
when we only need the maximum LENGTH.

We only need to check if a bigger length
can be achieved.
```

So:

```text
Length only → `if` can be used in suitable cases
Actual subarray → use proper full shrinking
```

---

## 5. Positive Numbers Matter

The simple sum-based sliding window works naturally when values are positive because:

```text
Expand → sum increases
Shrink → sum decreases
```

With negative numbers, this behavior can break.

---

## 6. Pattern Recognition

```text
K consecutive
        → Constant Window

Longest + condition
        → Longest Window

Number of subarrays
        → Counting / Pattern 2 idea

Shortest / Minimum
        → Minimum Window
```

---

# Final 4-Line Revision

```text
Constant → Fixed window size

Longest  → Shrink when invalid → MAX

Count    → Count valid windows
           / use <= K - <= K-1 for exact K

Minimum  → Shrink while valid → MIN
```
